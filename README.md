# YT Intel One

**Public product site** for [youtube-intel-scan](https://github.com/brianference/youtube-intel-scan).

**Live:** https://yt-intel-one.pages.dev

Marketing homepage, demo insight catalog, features, light/dark theme, and grounded AI chat. The full Express + Postgres + Python app lives in the main repo.

## Develop

```bash
npm install
npm run dev
npm run build
npx wrangler pages deploy dist --project-name yt-intel-one --branch main
```
