# YouTube Intel Scan — UX & feature plan (locked)

**Public site:** https://yt-intel-one.pages.dev  
**Canonical repo:** https://github.com/brianference/youtube-intel-scan  
**Deploy target:** yt-intel-one (not a separate product story)

## Features (this execution on public site)

1. Pipeline stepper (Ingest → Transcript → Analyze → Export)  
2. Category filter on insights  
3. RICE visual bars  
4. Live Supabase badge when `/api/insights` returns data  
5. Export-selected insight as markdown (client-side)  

## UX (this execution)

2. Insight cards with priority + category chips  
3. Loading / empty / live states  
4. Link to full-stack repo for native app path  
5. Honest demo vs live labeling
